# Cafeverse 1.0.0 (2026111710) — internal QA candidate

This is an **internal TestFlight QA candidate**, not a production-ready App Store release. The 300-case matrix explicitly contains NOT RUN, BLOCKED, NOT IMPLEMENTED and a failed production release gate. It must not be represented as 300 passed tests.

## Verified work

- Replaced iOS HTMLAudioElement.volume music control with bundled AVAudioPlayer playback and separate master/music/effects gains. Browser fallback uses actual Web Audio gain nodes plus limiter/voice cap. Hardware volume stays under iOS control; `.ambient` respects Ring/Silent.
- Added persistent, localized audio sliders, mute/restore, preview effect, bounded concurrent effects, foreground/background/interruption and route handling. Call speech uses the configured effect gain rather than a hardcoded full volume.
- Fixed a real boot ReferenceError: screens.js called refreshAppScreen before service-board.js introduced serviceMode. The service board script now loads first.
- Native gain math, native bridge type-check, game/security regression suites and six browser groups passed. The browser QA used real Chrome AudioContext/OfflineAudioContext and measured PCM attenuation at 100/50/10/0. Viewports: 375×667 Turkish, 393×852 English, 820×1180 Turkish. Screenshots are in outputs/qa-1.0.0.
- Normal Mac-session unsigned Release build succeeded for 1.0.0 / 2026111710. Signed archive/upload is reported only when actual logs confirm success.
- Device language defaults to Turkish for Turkish and English otherwise; manual choice remains available.
- Private free-plan Supabase staging was deployed and six real PostgreSQL race/rollback tests passed; all synthetic schemas were removed and live saved balances/auth users were unchanged. No paid branch or plan upgrade was created.
- Added gated marketplace/auction backend, escrow, commissions, bidding, outbid refunds, anti-sniping, SQL settlement and unit coverage. This is not enabled for players. The new market UI is behind the same gate; not visually certified as a completed production feature.
